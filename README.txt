DEAD ZONE A-Z – Survival Solitaire
================================
Eigenständige, werbefreie Zombie-Survival-Variante von Solitaire A-Z.

INSTALLATION
1. Neues öffentliches GitHub-Repository anlegen, z.B. dead-zone-a-z.
2. index.html, icon-180.png und sw.js aus dieser ZIP ins Hauptverzeichnis hochladen.
3. Settings > Pages > Deploy from a branch > main / (root).
4. Die von GitHub angezeigte Pages-Adresse öffnen.

Die Speicherstände sind von Solitaire A-Z getrennt.
Dieses Spiel verwendet keine offiziellen The Walking Dead Logos, Figuren oder Grafiken.
